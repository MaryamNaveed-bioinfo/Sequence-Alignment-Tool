Sequence Alignment Tool
A GUI-based bioinformatics desktop application for performing and visualizing biological sequence alignments. Built with Python and Tkinter, it supports Global Alignment (Needleman-Wunsch), Local Alignment (Smith-Waterman), and Multiple Sequence Alignment (MSA) with customizable scoring parameters and color-coded visual outputs.
Features
?Manual sequence input or FASTA file upload
?Global, Local, and Multiple Sequence Alignment
?Customizable scoring (match, mismatch, gap penalties)
?Color-coded alignment visualization
?Statistical analysis (identity, similarity, gaps)
?Export results as .txt or .aln files
Built With
?Python
?Tkinter
Who is it for?
Students and researchers in bioinformatics who need an easy-to-use tool for DNA/protein sequence analysis - no programming knowledge required
